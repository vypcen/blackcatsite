Подробнее о функции

TB-01

Тест-кейсы

Единая библиотека проверок вместо таблиц Excel.

  • Пошаговые кейсы: у каждого шага действие, ожидаемый результат и тестовые данные
  • Чек-листы — короткие проверки без шагов
  • Папки любой вложенности, теги, приоритеты и свои поля
  • Общие шаги: блок вроде «Войти в систему» пишется один раз и вставляется во все кейсы
  • Наборы данных: один кейс проверяется с разными значениями, каждый набор отмечается отдельно
  • Шаблоны, массовое редактирование, история версий
  • Ревью: коллеги утверждают кейс или возвращают на доработку

TB-02

Прогоны

Проверка набора кейсов на конкретной сборке — быстро и без потерь.

  • Прогон привязан к сборке, окружению и релизу; прошлые результаты сохраняются, регрессы видны сразу
  • Результат и фактический результат по каждому шагу
  • Скриншоты и логи — перетаскиванием или через Ctrl+V
  • Режим выполнения: список и карточка рядом, отметки клавишами P / F / B / S в любой раскладке
  • Автоматическое распределение кейсов между тестировщиками по нагрузке
  • Один план — сразу на несколько конфигураций (браузеры, ОС, стенды) со сводной матрицей
  • Перезапуск упавших кейсов на новой сборке одной кнопкой

TB-03

Баги

От найденной ошибки до исправления — без потери деталей.

  • Баг из упавшего шага одной кнопкой: шаги, ожидаемый и фактический результат подставляются сами
  • Понятный цикл: новый → в работе → исправлен → проверен → закрыт
  • Серьёзность, исполнитель, окружение, вложения, связь с кейсом, прогоном и релизом
  • Комментарии с @упоминаниями и уведомления в приложении и по почте
  • Разработчики работают с багами, не занимая полное место в лицензии
  • Передача в Jira, YouTrack, GitLab, GitHub и Redmine с синхронизацией статусов

TB-04

Автотесты

Результаты автотестов — в одной картине с ручным тестированием.

  • Приём результатов Playwright, JUnit XML и Allure: повторы, шаги, параметры, скриншоты падений
  • Утилита для CI сама определяет ветку, коммит и номер сборки в GitLab, GitHub Actions, Jenkins, TeamCity, Bitbucket, Azure DevOps
  • Автотест связывается с ручным кейсом по номеру в названии, тегу или метке
  • Система сама находит нестабильные тесты; тесты на карантине не роняют сборку
  • Запуск автотестов в CI прямо из интерфейса
  • Вебхуки о событиях — в мессенджеры и свои системы

TB-05

Требования и покрытие

Доказательство для заказчика, что всё нужное проверено.

  • Требования вручную или импортом из CSV и Jira
  • Связь «требование — тест-кейсы — результаты — баги»
  • Статус каждого требования: пройдено, частично, провалено, не проверено, не покрыто
  • Матрица покрытия по последним результатам, по релизу или по прогону
  • Список кейсов, не привязанных ни к одному требованию
  • Выгрузка матрицы в Excel, PDF и CSV для приёмки и аудита

TB-06

Отчёты и аналитика

Ответ на «готов ли релиз» — за минуту.

  • Тест-планы, релизы и спринты; страница готовности релиза с выводом «готов» или «что мешает»
  • Отчёт по прогону и тест-плану в PDF и Excel одной кнопкой
  • Динамика заведённых и решённых багов, открытые баги по серьёзности
  • Процент прохождения автотестов, чаще всего падающие кейсы, нестабильные тесты
  • Нагрузка исполнителей в открытых прогонах
  • Аналитика открывается мгновенно даже на больших проектах

TB-07

Безопасность

Готово к требованиям службы безопасности заказчика.

  • Единый вход: OpenID Connect (Keycloak, ADFS), LDAP / Active Directory, Kerberos; группы каталога назначают роли
  • Двухфакторная аутентификация с резервными кодами; политика паролей, тайм-аут, лимит сессий
  • Встроенные роли и свои роли из 16 разрешений; роль может отличаться по проектам
  • Журнал аудита: входы, права, удаления, выгрузки — с фильтрами и выгрузкой в CSV
  • 152-ФЗ: согласие при регистрации, выгрузка и обезличивание данных пользователя
  • Корзина и резервные копии с автоматической проверкой восстановления
  • Работает на ваших серверах, может обходиться без интернета

TB-08

Переезд

Переход с другой системы без ручного копирования.

  • Перенос проектов из TestRail, TestLink и Qase
  • Импорт из Excel и CSV, в том числе выгрузок Zephyr Scale и Xray
  • Мастер сам сопоставит колонки, разберёт шаги и покажет результат до загрузки
  • Полный экспорт проекта в любой момент — данные остаются вашими
  • HTTP API с токенами — для интеграции со своими системами
